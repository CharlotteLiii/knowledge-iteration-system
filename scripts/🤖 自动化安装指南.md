# 🤖 自动化任务安装指南

## 方案 A：手动启动测试（推荐先试）

不需要安装定时任务，先在知识库根目录运行 dry-run：

```bash
cd "<你的 Obsidian Vault / 知识库根目录>"
python scripts/run_all.py --dry-run --preflight
```

确认路径和四层结构都正确后，再运行单项任务：

```bash
python scripts/run_all.py --only daily --days 2
```

或全量运行：

```bash
python scripts/run_all.py
```

> macOS/Linux 如果你的命令是 `python3`，可以把上面的 `python` 换成 `python3`。

## 方案 B：初始化 / 预检

首次分享给别人使用、迁移电脑、或四层目录不确定时，先运行：

```bash
python scripts/setup_preflight.py
```

只查看将要创建什么：

```bash
python scripts/setup_preflight.py --create-missing --dry-run
```

确认后补齐缺失目录并写入默认配置：

```bash
python scripts/setup_preflight.py --create-missing
```

配置文件位置：

```text
.knowledge-iteration-system.json
```

## 方案 C：macOS 设置每两天自动运行

注意：LaunchAgents 需要绝对路径，所以 `com.karpathy.knowledge.distiller.plist` 会包含当前 Vault 的绝对路径。如果移动了 Vault，请重新运行 `bash scripts/install_automation.sh` 安装。

当前 macOS 配置是：**每 48 小时运行一次，每次扫描最近 2 天的内容**。

安装前先预览：

```bash
bash scripts/install_automation.sh --dry-run
```

确认后安装 launchd 定时任务：

```bash
bash scripts/install_automation.sh
```

卸载：

```bash
bash scripts/install_automation.sh --uninstall
```

## 方案 D：Windows 设置每日自动运行

Windows 使用 Task Scheduler / 任务计划程序。

先在 PowerShell 里预览：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\install_automation.ps1 -DryRun
```

确认后安装：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\install_automation.ps1
```

卸载：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\install_automation.ps1 -Uninstall
```

## 方案 E：Linux 设置每日自动运行

Linux 使用 cron：

```bash
bash scripts/install_automation_linux.sh --dry-run
bash scripts/install_automation_linux.sh
bash scripts/install_automation_linux.sh --uninstall
```

## macOS 常用管理命令

```bash
# 查看任务状态
launchctl print gui/$(id -u)/com.karpathy.knowledge.distiller

# 立即运行一次（测试用）
launchctl kickstart -k gui/$(id -u)/com.karpathy.knowledge.distiller

# 停止任务
launchctl bootout gui/$(id -u) ~/Library/LaunchAgents/com.karpathy.knowledge.distiller.plist

# 查看运行日志
cat "scripts/distill.log"
cat "scripts/distill.error.log"
```

## 更简单的方式

如果觉得定时任务太复杂，可以先不安装自动化：

1. 每天或每周打开 Agent / Codex
2. 输入「跑 daily」或「知识蒸馏」
3. 让 Skill 调用 `python scripts/run_all.py --only daily --days 2`

这样更灵活，也更不容易被自动化把知识库搅成奶昔。
