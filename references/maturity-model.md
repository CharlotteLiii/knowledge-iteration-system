# 成熟度模型

## 想法成熟度

| 阶段 | 标记 | 特征 | 判定标准 |
|------|------|------|----------|
| 种子想法 | 🌱 | 只有点子，几句话 | 行数 < 10，无关联链接 |
| 发芽想法 | 🌿 | 有框架，关联了资料 | 行数 >= 10，有链接，或有框架 |
| 成熟想法 | 🌳 | 完整方案，可落地 | 行数 >= 30，有框架，链接 >= 3 |
| 已落地 | ✅ | 已产出成果 | 内容中包含"已发表/已完成/已落地"等标记 |

额外判断字段：**继续投入价值**（高 / 中 / 低）
不是每颗种子都要长成红杉树，有些想法该安详地躺在土里。

## Skill 成熟度

| 等级 | 名称 | 特征 |
|------|------|------|
| Level 0 | 普通笔记 | 没有 Skill 潜力 |
| Level 1 | 重复出现的问题 | 同类需求多次出现 |
| Level 2 | 有稳定处理步骤 | 可以写出步骤 |
| Level 3 | 有输入输出和判断标准 | 边界清晰 |
| Level 4 | 可写成 Skill 草案 | 有完整结构 |
| Level 5 | 已验证，可正式沉淀 | 经过实践检验 |

## 升级路径

### 种子 → 发芽
- 扩充内容到 15 行以上
- 建立关联：链接相关 Clippings 或想法
- 补充背景：来源、解决什么问题
- 拆解问题：包含哪些关键子问题

### 发芽 → 成熟
- 更多关联：至少 3 个链接
- 建立实施框架：具体步骤、里程碑
- 识别风险
- 资源评估：需要什么人、工具、时间

### 成熟 → 已落地
- 设置里程碑和检查点
- 产出实际成果
- 回流到知识库
